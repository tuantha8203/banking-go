- (decision) Stakes: sản phẩm thật lên production — compliance và bảo mật nghiêm ngặt
- (decision) Form factor: backend Go + web admin cho nhân viên vận hành
- (decision) Working mode: coaching path
- (change) Stakes điều chỉnh: không có user/khách hàng thật; user tự đóng vai khách hàng và vận hành. 'Production' = chuẩn kỹ thuật production, không phải sản phẩm thương mại
- (decision) Mục tiêu chính: học sâu core banking + portfolio
- (decision) Chuẩn production bắt buộc v1: đúng tiền tuyệt đối (double-entry, idempotency, đối soát); bảo mật + audit; vận hành thật (CI/CD, observability, runbook, rollback); chịu tải + HA
- (decision) Hệ thống ngoài (NAPAS, eKYC, OTP...) ở v1: mock service có hành vi lỗi/timeout giống thật
- (assumption) Thời gian: không giới hạn cứng, làm đến khi đủ tính năng — cần chốt danh sách tính năng định nghĩa 'xong'
- (decision) Phạm vi nghiệp vụ 'xong': KH+tài khoản+ledger kép; nạp/rút/chuyển nội bộ+liên NH (NAPAS mock)+OTP+hạn mức; đối soát+EOD; tiết kiệm có kỳ hạn+lãi
- (change) Form factor mở rộng: backend Go + web admin + web khách hàng (internet banking)
- (decision) Vai admin: giao dịch viên/vận hành, kiểm soát viên (maker-checker), kế toán/đối soát, quản trị hệ thống
- (decision) Chia 4 release: R1 KH/tài khoản/ledger/nạp-rút/chuyển nội bộ/audit/admin cơ bản+CI/CD+observability; R2 liên NH NAPAS mock+OTP+hạn mức+maker-checker+web KH; R3 đối soát+EOD+báo cáo+load test/HA; R4 tiết kiệm+lãi+tất toán. Mỗi release đạt đủ chuẩn production cho phần của nó
- (decision) Ngoài phạm vi: thẻ, cho vay/tín dụng, đa tiền tệ/FX (chỉ VND), mobile app
- (decision) Có phí giao dịch, bảng phí cấu hình được, hạch toán vào tài khoản thu phí
- (decision) Đúng tiền: bất biến tổng Nợ=tổng Có mọi lúc; chaos test (concurrency, kill process/DB, retry trùng) → 0 lệch, 0 nhân đôi; chạy trong CI
- (decision) Hiệu năng: API chuyển khoản 500 TPS, p95 < 200ms, có báo cáo k6
- (decision) HA: SLO 99.9%; failover test kill instance/DB primary dưới tải → không mất giao dịch, phục hồi < 1 phút
- (decision) Portfolio đạt khi: demo E2E trên staging mỗi release (kịch bản 5 phút); tài liệu kiến trúc + ADR; báo cáo load/chaos test; ít nhất 1 postmortem/runbook sự cố giả lập
- (decision) Bối cảnh pháp lý: mô phỏng Việt Nam tham khảo (tinh thần quy định NHNN về eKYC, xác thực theo hạn mức, lưu trữ, AML cơ bản) + PCI/OWASP; không cam kết tuân thủ thật
